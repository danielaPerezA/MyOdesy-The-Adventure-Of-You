# MyOdesy-The-Adventure-Of-You
MyOdesy, es una aplicación tipo "Tracker life" diseñada para ayudar a los jóvenes adultos a construir y mantener hábitos positivos en dos pilares: Finanzas y Fitness. Convierte el seguimiento personal en una experiencia motivadora por medio de la gamificación, permitiendo visualizar su progreso, mantener rachas y establecer recompensas
